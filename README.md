# 学习工作台 · 我的大学三年计划

> 三年（2026–2029）逐天拆解的日程工作台 + 网安新手练习台 + 华为 ICT 大赛备赛专区。
> 纯静态、单文件为主，**打开就能用**，支持离线（Service Worker / PWA）。

---

## 一、项目要解决的问题

大学生活节奏碎、事项杂：课程、考证、比赛、实习、专升本（专插本）准备全挤在一起，
靠脑子记或零散便签很容易漏掉关键节点，等到大三才发现学历 / 方向没规划好就晚了。

这个项目把「大学三年」拆成约 130 周、逐天可执行的计划，并配套一个**练手即用的网安练习台**
和 ICT 大赛备赛区，目标是让计划不是「写下来」，而是「每天打开就知道该干什么、能立刻练」。

核心理念：**条理清晰、具体到天、打开就能练。**

---

## 二、主要功能

| 模块 | 说明 |
| --- | --- |
| **三年计划工作台**（`index.html`） | 130 周三年视图、本周视图、课程 / 考证 / 实习节奏；专升本（专插本）关键窗口倒计时提醒 |
| **网安练习台**（`practice.html`） | 每日练、靶场入口、题单、进度记录，覆盖 Web / 系统 / 数据库等基础题型 |
| **ICT 备赛专区**（`ict.html` + `modules/`） | 华为 ICT 大赛备赛外壳 + 五个子模块：备赛总览 / 视频精讲 / 理论题库 / 实验实操 / 闯关练习台 |
| **离线 & 安装**（`sw.js` + `manifest.webmanifest`） | PWA 离线缓存，可「安装到桌面 / 手机主屏」 |
| **数据**（`data/`） | 课表原始数据（示例）、生涯规划素材等 |

三条交付线（同一份页面源生成）：资料库在线页、手机 PWA、桌面应用（Electron exe）。

## 三、安装方法

无需构建、无依赖，两种用法：

**方式 A · 直接打开**
用浏览器打开 `index.html` 即可。

**方式 B · 本地静态服务器（推荐，完整离线 / 安装能力）**

```bash
# 在项目根目录执行，SW 在 file:// 下不生效，需用 http(s)://
python -m http.server 8000
# 浏览器打开 http://localhost:8000/index.html
```

**部署到 GitHub Pages / 任意静态托管**
直接把仓库根目录作为站点根发布即可；如需 PWA 安装能力，托管需支持 HTTPS。

## 四、使用示例

1. **看本周安排**：打开 `index.html` → 本周视图直接显示这周的课程、考证、节点。
2. **每天练一题**：打开 `practice.html` → 选模块 → 做题并记录进度，数据存本地（`localStorage`）。
3. **备赛 ICT**：打开 `ict.html` → 进入子模块刷理论题 / 做实验 / 闯关。
4. **离线 / 安装**：用方式 B 托管后，浏览器「安装」到桌面或手机主屏，断网也能用。

---

## 修改页面后必做

改了任一 HTML / JS 内容，**必须同步 bump `sw.js` 里的 `CACHE` 版本号**
（连同各页面里 `register('sw.js?v=…')` 的 `?v=` 参数），否则 Service Worker 会继续吐旧缓存。

## 技术栈

原生 HTML / CSS / JavaScript，无框架。数据存 `localStorage`。
