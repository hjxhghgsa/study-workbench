照着敲一遍，比看十遍强

国赛和省赛复赛考的是 8 小时综合实验，纯理论背得多不等于做得出来。这里把两个赛道的高频实验按 「目标 → 拓扑要点 → 关键命令 → 验收标准」拆开，命令可直接复制。建议顺序做完，每做完一个自己 display 一遍验证结果。

第 0 步 · 环境准备

先把工具装齐，后面所有实验都跑在这套环境里。

eNSP（必装）

华为官方企业网络仿真平台，模拟 AR 路由器 / S 系列交换机 / USG 防火墙 / WLAN 设备。装完装 VirtualBox，再在「工具 → 设备包管理」里下载 AR、USG 等设备包，否则设备起不来。

support.huawei.com → 搜 eNSP ↗
虚拟机（必装）

基础软件赛道要真机环境。VMware Workstation 或 VirtualBox + openEuler 22.03 LTS 镜像，建议 4 核 8G 起。

openEuler 镜像下载 ↗
抓包工具

Wireshark，eNSP 可直连调用。用来抓 OSPF 报文、TCP 三次握手、CAPWAP、VXLAN 封装，理解协议最快的方式。

wireshark.org ↗
官方文档（边做边查）

openEuler 与 openGauss 的官方文档，是基础软件赛道最权威的参考。

docs.openeuler.org ↗
docs.opengauss.org ↗
eNSP 安装三个坑：① 安装路径绝不能有中文，否则设备无法启动；② 安装包右键以管理员身份运行，装完在 Windows 防火墙里放行 eNSP 相关进程；③ 路由器起不来时，用「工具 → 注册设备」重新注册 AR_Base。
